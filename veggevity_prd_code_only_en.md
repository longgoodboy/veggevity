PRODUCT REQUIREMENTS DOCUMENT
Project: Veggevity – Code-only Website Prototype for Vegan Commerce & Nutrition Communication
I. Product Overview
1. Project Name

Veggevity

2. Product Type

Veggevity is a code-only website prototype built with HTML, CSS, and JavaScript.

The website simulates a digital business model for vegan food commerce and nutrition communication. It combines:

Vegan food/product showcase
Nutrition education
Blog and knowledge content
Basic nutrition consultation
Lightweight chatbot demo
Customer need collection through a consultation form

The project is designed for a business/economics context, so the technical implementation should remain simple and easy to explain.

3. New Technical Direction

The project will not use WordPress, Elementor, WooCommerce, PHP, MySQL, or CMS plugins.

Instead, the website will use:

HTML for page structure
CSS for visual design, layout, typography, and responsive behavior
JavaScript for interactive features
Local/static data stored in JavaScript or JSON
Static pages that can run locally or be deployed to platforms such as Vercel, Netlify, GitHub Pages, or TiinyHost
4. Reason for the Change

The project originally considered WordPress, Elementor, and WooCommerce. However, the updated direction is to use code only because:

The project is intended for a business/economics audience.
The website should demonstrate a digital business model, not complex system development.
A static prototype is easier to present, test, and explain.
The team can focus on customer experience, digital transformation, nutrition communication, and brand strategy.
The existing static prototype already contains important features that should be preserved.
II. Product Vision

Veggevity aims to help users:

Eat vegan more confidently through clear food choices, simple nutrition guidance, and friendly consultation support.

The website should feel like a combination of:

A vegan starter guide
A vegan food shop
A nutrition education hub
A cookbook/editorial website
A simple consultation channel

The goal is not to build a full e-commerce system, but to create a convincing prototype that demonstrates how a vegan food brand can use a website to support sales, education, and customer relationship building.

III. Product Goals
1. Business Goals
Demonstrate digital transformation for small vegan food businesses.
Present vegan products in a clearer and more trustworthy way.
Connect product discovery with nutrition education.
Use blog and nutrition content to build brand credibility.
Collect customer needs through a consultation form.
Create a strong brand identity based on a natural, botanical, and elegant visual direction.
2. User Goals

Keep the technical implementation understandable for business/economics students.

3. Technology Acceptance Model — TAM

The Technology Acceptance Model is used to explain how users accept and use a digital website in a food business context.

TAM focuses on two key factors:

Perceived Usefulness

Users are more likely to use the website if they feel it helps them make better food and nutrition decisions.

In Veggevity, this is supported by:

Product filters
Nutrition lookup tool
Blog articles
Consultation form
Clear product labels and nutrition badges
Perceived Ease of Use

Users are more likely to accept the website if it is easy to read, easy to navigate, and easy to interact with.

In Veggevity, this is supported by:

Simple navigation
Readable typography
Clear page structure
Mobile-friendly layout
Easy-to-use forms
Short and practical explanations
